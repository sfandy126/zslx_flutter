## 详细组件分析

### MDUser用户管理系统
**新增** MDUser是基于SharedPreferences构建的用户状态管理系统，提供完整的用户认证和数据持久化功能。

#### 核心特性
- **单例模式**：通过`MDUser.defualt`提供全局访问点
- **响应式更新**：继承`ChangeNotifier`，支持状态监听
- **多数据类型支持**：认证令牌、用户ID、游客标识、昵称、头像、手机号
- **事件机制**：内置登录、登出、信息更新等事件广播
- **游客模式**：支持未登录用户的UUID管理和数据持久化

#### 数据存储结构
```dart
// 用户认证信息
_priToken: String?     // 认证令牌
_priUid: String?       // 用户ID  
_priGuest: String?     // 游客标识

// 用户档案信息
_priNick: String?      // 用户昵称
_priAvatar: String?    // 用户头像
_priPhone: String?     // 手机号码

// 微信绑定信息（不持久化）
wxOpenid: String?      // 微信OpenID
wxName: String?        // 微信名称
```

#### 关键API
- `init()`：应用启动时初始化，从SharedPreferences加载用户数据
- `login(res)`：登录成功，保存认证信息和用户资料
- `logout()`：登出，清除所有本地数据并触发事件
- `update(res)`：更新用户信息
- `saveForGuest(uuid)` / `readForGuest()`：游客UUID管理
- `saveLast(phone, passwd)` / `readLast()`：最近登录账户管理

#### 使用示例
```dart
// 应用启动时初始化
await MDUser.defualt.init();

// 登录流程
await MDUser.defualt.login({
  'token': 'user_token',
  'user_id': '123456',
  'is_yk': '0',
  'nickname': '张三',
  'avatar': 'https://example.com/avatar.jpg',
  'phone': '13800138000'
});

// 检查登录状态
if (MDUserExtension.islogined) {
  print('用户已登录: ${MDUser.defualt.uid}');
}

// 游客模式
String guestId = await MDUser.readForGuest();
```

- 依赖声明与版本：见 pubspec 依赖项

- **MDUser集成**：通过统一的SaveKey枚举管理键名，避免冲突
- 基本数据类型：支持 String、int、double、bool、List<String> 等
- 复杂数据：建议将对象序列化为 JSON 字符串后再存储；读取时反序列化
- 异步操作：所有读写均为异步，需 await 或 then 处理
- 命名空间：按功能模块划分 key 前缀，避免冲突（如MDUSER_前缀）

- 性能建议：批量写入合并；避免频繁小写；大对象缓存到内存再落盘
- 兼容性：跨平台一致 API；注意不同平台底层实现差异（如 Android SharedPreferences vs iOS UserDefaults）

## 性能考虑
- **MDUser系统**
  - 单例模式避免重复实例化开销
  - ChangeNotifier实现高效的状态更新通知
  - SharedPreferences异步操作避免阻塞UI线程
  - 合理的数据结构设计，减少不必要的序列化/反序列化
- shared_preferences
  - 避免在热路径频繁读写；合并多次写入
  - 复杂数据以 JSON 字符串形式存储，减少对象序列化开销
  - 合理设置默认值，降低冷启动时的等待
- device_info_plus
  - 按需获取，结果可缓存；避免每次渲染都查询
  - 对受限信息做降级处理，防止阻塞 UI
- common_utils
  - 选择合适的数据结构与算法；避免不必要的字符串拼接
  - 加密操作耗时较高，尽量异步执行并反馈进度
- oktoast
  - 控制显示频率与时长，避免覆盖重要信息
  - 在列表滚动等高刷新场景谨慎使用
- color
  - 颜色对象复用；避免重复解析十六进制字符串
  - 主题色集中管理，减少分散硬编码

## 故障排查指南
- **MDUser系统**
  - 现象：用户数据丢失或状态异常
  - 排查：检查SharedPreferences键名是否正确；确认init()是否被调用；验证数据格式
  - 参考：MDUser的init方法和_save方法实现
- shared_preferences
  - 现象：读不到数据或崩溃
  - 排查：检查 key 是否一致；确认异步完成；查看平台日志
  - 参考：Android 插件注册与错误日志输出
- device_info_plus
  - 现象：无法获取设备信息
  - 排查：确认平台权限；检查返回值是否为空；区分平台差异
  - 参考：Android/iOS 插件注册
- oktoast
  - 现象：提示不显示或样式异常
  - 排查：检查是否在正确的上下文中调用；确认主题配置
- color
  - 现象：颜色解析异常
  - 排查：检查十六进制格式；确认长度与透明度处理逻辑
